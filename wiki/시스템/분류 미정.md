### 🧠 project_skill_popup

**오피스 채팅에서 /입력 시 프로젝트별 스킬 목록 팝업 표시 — .claude/skills/ 폴더에서 동적 파싱**

오피스 채팅 메시지 입력창에서 `/` 입력 시 스킬 팝업을 표시하는 기능 추가 예정.

**Why:** 프로젝트마다 스킬이 다르므로 하드코딩 불가. `.claude/skills/*/SKILL.md`에서 동적으로 읽어야 함.

**How to apply:**
- `.claude/skills/` 폴더의 SKILL.md에서 스킬명 + 한글 설명 파싱
- `GET /api/skills` API 엔드포인트 추가
- 프론트엔드: 오피스 채팅 입력창에서 `/` 타이핑 시 자동완성 팝업
- 각 LLM별 사용 가능한 스킬 필터링
- 클릭 시 자동 입력

출처: 세션 메모리 `project_skill_popup.md` · type=project
