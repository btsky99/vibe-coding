### 🧠 project_multi_instance_ports

**멀티 인스턴스 포트 대역 지도 + 슬롯 해시 규칙. 서버 9000-9009(5슬롯)·오피스 9010+·heartbeat 9019. 포트 로직 건드리기 전 필독**

2026-07-22 구현. "개발+설치본" 및 "서로 다른 프로젝트 설치본 2개" 동시 실행 지원.

**증상(고친 것):** 동시 실행 시 하나 닫으면 나머지 터미널 콘솔 전멸 + 나중 켠 auto 미동작.
**근본원인:** `resolve_server_ports`의 test-bind→close→real-bind TOCTOU로 두 인스턴스가
같은 http/ws(9000/9001) 선택 → 나중 PTY가 먼저 인스턴스 포트에 얹힘 → 먼저 닫으면
graceful_shutdown이 그 PTY 죽임. 폴백 9010 하드코딩은 오피스 대역 침범.

**포트 대역 지도 (불변 — 넘지 말 것):**
- `9000-9009` = 서버 http/ws 쌍 5슬롯 (http=짝수, ws=http+1). `instance_lock._server_port_slot_base`
- `9010-9018` = 오피스 서버 (인스턴스별 auto-scan, `office_server.py`)
- `9019` = heartbeat/auto 싱글턴 락 (전역 하나, [[업데이트와 배포]])
- `19001+hash%480` = 인스턴스 단일화 락 포트 (서버 포트와 별개)
- server_locator 스캔 = 9000-9019, project_id 슬러그 대조로 자기 서버 선택

**슬롯 규칙:** `9000 + (md5(str(project_root)[+'::frozen'])%5)*2`. 인스턴스 락과 동일 시드라
dev/frozen·프로젝트마다 결정적 분리. vibe-coding: dev=9000/설치본=9008.
**한계:** 5슬롯 mod라 다른 프로젝트가 같은 슬롯 떨어질 확률 1/5 → 대역 내(9000-8) 폴백 흡수.
**6개 이상 동시 실행 = 대역 포화로 미지원.** VIBE_PORT_BASE 명시 시 항상 우선(smoke 격리).

**auto 관련:** enabled는 DB 공유값이라 dev+설치본 양쪽 ON으로 보이지만 실행 주체는 9019 락
쥔 하나뿐. `is_active_holder()` → `/api/heartbeat/status.active_here` → 헤더 칩 'AUTO 대기'
(⏸️)로 나중 인스턴스 대기 상태 표시. 먼저 창 닫으면 60초 내 자동 인수.

**🔴🔴 좀비 락 포트 (2026-08-14, 커밋 24006ac):** "개발 서버가 실행해도 아무 일도 안 남"의
진범이 여기다. 커널 대기(`wait=Executive`)에 갇힌 좀비 pythonw가 락 포트를 영구 점유하면
`acquire_single_instance_lock`이 bind 실패 → `os._exit(0)`으로 **매번 조용히 즉사**한다.
- **증상 지문:** `server.log`에 `--- Server Started ---`만 반복되고 **본문 0줄**.
  포어그라운드 실행은 **exit 0 + 출력 0줄**. 방금 고친 코드가 원인으로 오인되기 쉽다.
- 🔴 **관리자 권한 `Stop-Process`가 `kill=ok`를 반환해도 `alive=True`** — 커널 대기라
  재부팅 전엔 안 죽는다. py-spy는 `os error 5`로 접근 거부. "죽였다"를 믿지 말 것.
- **진단 순서:** ①락 포트 계산(`19001+md5(root)%480`, dev vibe-coding=**19276**)
  ②`Get-NetTCPConnection`으로 점유자 확인 ③`(Get-Process).Threads.Count`가 **1**이면 좀비.
- 수정: 락 소켓에 생존 핸드셰이크(listen+배너) 도입 → bind 실패 시 주인의 **생사를 판정**하고
  좀비일 때만 다음 포트로 회수. 🔴 확인 없이 비켜가면 v3.7.179 이전 '창 2개' 버그로 회귀.

  주석만 "좀비 회수" 라고 적혀 있었다 — **주석이 구현을 보증하지 않는다.**

### 모듈 상단 `[WHY]` `[제약]`

uv 는 --python 3.11 로 없는 버전을 알아서 받아 온다 — 그래서 uv 를 먼저 본다.
[제약] 이 스크립트는 앱 venv 에서 돈다. 만들어지는 것은 다른 venv 다 —
자기 자신에게 설치하지 않는다.
