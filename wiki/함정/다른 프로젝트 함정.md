### certbot ACME 검증이 계속 404로 실패 (Invalid response from .../.well-known/acme-challenge/...)

- **원인** — nginx 80 블록에 서버 레벨 return 404 가 있었다. nginx 는 server-level return 을 rewrite 페이즈에서 실행하고 location 선택을 건너뛰므로, location ^~ /.well-known/acme-challenge/ 가 평가조차 되지 않는다. certbot --nginx 가 임시 location 을 주입해도 무력. 여기에 Let's Encrypt 리졸버가 옛 IP 를 1시간 넘게 캐시한 것이 겹쳐 원인 판별이 늦어졌다
- **수정** — 80 블록에서 서버 레벨 return 을 제거하고 acme location 을 최우선으로 둔다. certbot 을 쏘기 전에 probe 파일을 놓고 외부 경로로 200 을 확인한다 — LE 는 실패도 레이트리밋에 세므로(도메인·계정당 5회/시간) 연타하면 창을 태워 더 늦어진다
