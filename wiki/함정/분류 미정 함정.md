### PowerShell 5.1 (Get-Content -Raw)가 BOM 없는 UTF-8 한글 파일을 CP949로 읽어 재저장 시 전체 모지바케

- **원인** — PS 5.1 기본 인코딩이 ANSI(CP949) — -Raw 읽기+Set-Content 재저장 조합이 UTF-8 한글을 파괴함
- **수정** — 한글 파일 일괄 치환은 PowerShell 금지, Edit/Write 도구나 python으로 처리. 사고 시 컨텍스트에 남은 원본으로 Write 복구
- 출처: `incident_ledger` · 최초 2026-07-19

### 갤럭시탭 Termux에서 claude 실행 시 종료코드 159(SIGSYS, Bad system call)로 1.9초 만에 즉사

- **원인** — claude 2.x는 Bun 컴파일 네이티브 바이너리만 배포하는데, 그 바이너리가 쓰는 시스템콜이 Android 10(커널 4.4.205) seccomp 필터에 차단됨. --version/--help/auth status는 통과하나 인증 후 실제 세션 시작 시 사망. --bare도 인증되는 순간 동일 → keychain은 범인 아님
- **수정** — claude 1.0.128(cli.js 9.3MB 순수 JS)을 ~/claude1에 별도 설치하고 PREFIX/bin/claude를 'exec node cli.js' 래퍼로 교체. Node 런타임 syscall만 쓰므로 seccomp 통과. 인증은 PC에서 claude setup-token 발급 → 탭 .bashrc에 CLAUDE_CODE_OAUTH_TOKEN 등록
- 출처: `incident_ledger` · 최초 2026-07-25

### settings.json hooks: Expected array, but received undefined (UserPromptSubmit.1 / Stop.2)

- **원인** — setup_doctor.check_hooks가 이벤트 배열 원소를 flat {type,command}로 가정 — 그룹 {matcher,hooks}에 .get('command')를 읽어 항상 ''를 얻어 기존 훅을 누락으로 오판하고 flat 항목을 append. SetupBanner가 GET /api/setup/status를 부팅마다 호출해 손으로 지워도 재오염
- **수정** — _event_commands로 그룹 안쪽까지 감지 + _as_group으로 nested 기록 + _normalize_event로 기존 flat 잔재 청산, _REQUIRED_HOOKS에서 무의미한 $PROMPT argv 제거, test_setup_doctor.py 회귀 4건 추가
- 출처: `incident_ledger` · 최초 2026-07-30
