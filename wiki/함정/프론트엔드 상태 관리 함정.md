## 🔴 밟았던 것 (사고 장부)

### Claude Code 상태줄이 터미널 하단에 떴다가 사라짐 — statusline.py UnicodeEncodeError: 'cp949' codec can't encode character '⛶'

- **원인** — 한국어 Windows에서 PYTHONUTF8 영구 env 미설정 → Claude Code가 파이프로 statusline.py 실행 시 stdout이 cp949로 잡혀 블록 문자(U+26C1/U+26F6) 출력 실패 → exit 1 → 상태줄 숨김. 환경 따라 env 유무가 달라 '떴다 사라지는' 증상
- **수정** — statusline.py에 sys.stdout.reconfigure(encoding='utf-8', errors='replace') 추가 — 환경변수 의존 제거, 스크립트 자체에서 UTF-8 강제
- 출처: `incident_ledger` · 최초 2026-06-11

### 상태줄 컨텍스트 270k/200k tokens (135%) 오표시 + 라인1 오제거

- **원인** — [1m] 1M 컨텍스트 세션인데 Claude Code가 context_window_size를 200k로 보고. 라인1 자체 문제로 오판해 제거했으나 사용자가 원한 건 정상 표시
- **수정** — 라인1 복원 + 사용량이 보고된 창 크기 초과 시 분모를 1M으로 보정 (scripts/statusline.py, c4f02e2)
- 출처: `incident_ledger` · 최초 2026-06-11

### 설치본 AUTO 배지가 계속 'AUTO 멈춤'으로 표시 (데몬은 정상 동작 중)

- **원인** — App.tsx 판정식 게이트 대상 오류 — 주석은 '멈춤은 active_here=true일 때만' 불변식을 선언했으나 구현은 hbStale=stale && !hbWaiting. hbWaiting이 enabled=true를 요구해 '비주체+enabled=false+stale' 조합이 게이트를 통과. 락 비보유 인스턴스는 박동 주체가 남이라 자기 DB의 loop_beat_at이 늙는 게 정상인데 이를 hang으로 오판
- **수정** — hbStale 게이트를 !hbWaiting 대신 active_here !== false로 직접 변경 (undefined=구버전 서버는 하위호환 통과). 커밋 cab2480. 회귀 7종 검증 통과
- 출처: `incident_ledger` · 최초 2026-07-23

### 앱 재시작 시 모든 터미널 슬롯이 각자 지정한 폴더 대신 마지막 선택 폴더로 표시됨

- **원인** — 슬롯→프로젝트 맵(hive_slot_projects)을 localStorage에만 저장. Qt WebEngine localStorage는 project_name(=서버 last_path 폴더명)으로 격리 저장돼, last_path가 바뀌면 재시작 시 다른 저장 버킷을 읽어 슬롯 맵 유실 → 모든 슬롯이 currentPath로 폴백
- **수정** — 슬롯 맵의 단일 진실을 인스턴스 단위로 안정적인 config.json(slot_projects 키)으로 승격. App.tsx가 마운트 시 /api/config에서 로드하고 변경 시 /api/config/update로 영속. localStorage는 캐시로만 유지
- 출처: `incident_ledger` · 최초 2026-07-24

### 재시작 후 t1이 t3 폴더로 뜸, 슬롯마다 재설정 필요

- **원인** — config.json(권위 소스) 로드가 콜드부트에서 거절될 때 .finally로 실패에도 slotProjectsLoaded=true를 세워, config 없이 bucket-격리 localStorage를 진실로 확정 → 일부 슬롯만 남고 나머지는 currentPath로 폴백
- **수정** — App.tsx slot_projects 로드에 재시도(0.5s×20) 추가, 서버 도달 성공 시에만 loaded=true, 실패 중 save 잠금 유지
- 출처: `incident_ledger` · 최초 2026-07-24
