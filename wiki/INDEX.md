# 바이브 코딩 위키

> **사람도 LLM 도 읽는 백과사전.** 로그가 아니다 — 여기 있는 건 "그래서 무엇이 참인가" 뿐이다.
> 쓰기 전에 [작성 규약](../.claude/rules/wiki.md)을 읽을 것.

## 한 줄

이 프로젝트에서 **코드만 봐서는 알 수 없는 것**(왜·불변식·제약·과거사고)을 모아둔 곳.
`wiki/*.md` 가 정본이고, DB(`zettel_notes`)는 여기서 만들어지는 검색 인덱스일 뿐이다.

## 어떻게 쓰나

| 상황 | 할 일 |
|---|---|
| 뭔가 찾을 때 | 아래 목차에서 고르거나, 세션 시작 시 자동 주입되는 회상을 본다 |
| 새로 알게 됐을 때 | **새 페이지를 만들지 말고** 해당 페이지를 고친다 (규칙 1) |
| 주장을 쓸 때 | `파일:줄번호` 또는 커밋 해시를 옆에 박는다 (규칙 3) |
| 세션에서 있었던 일 | 여기 쓰지 않는다. 그건 로그다 |
