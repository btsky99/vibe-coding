## Git 커밋 메시지 규칙

Conventional Commits 형식 + 한글 본문 필수. 제목 한 줄만 작성 금지.

### 타입
| 타입 | 용도 |
|------|------|
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변경 없는 구조 개선 |
| `docs` | 문서·주석 변경 |
| `build` | 빌드·패키징·배포 관련 |
| `chore` | 그 외 (설정, 의존성 등) |

### 필수 템플릿
```
<type>(<scope>): <한글 요약 — 50자 이내>

## 변경 이유 (Why)
배경과 근본 원인 설명.

## 변경 내용 (What)
- 파일명 — 구체적 변경 사항

## 영향 범위 (Impact)
다른 기능에 미치는 영향 (없으면 "없음" 명시)
```

### 금지 사항
- 제목 한 줄만 작성 (본문 생략 불가)
- 영어로만 작성 (본문은 반드시 한글)
- `--no-verify`로 훅 우회
