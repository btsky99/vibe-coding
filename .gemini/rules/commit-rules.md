## Git 커밋 메시지 규칙 (Gemini/Claude 공통)

모든 에이전트는 **Conventional Commits** 형식을 준수하며, 본문(Body)은 반드시 **한글**로 상세히 작성합니다.

### 표준 타입
| 타입 | 용도 |
|------|------|
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변경 없는 코드 구조 개선 |
| `docs` | 문서·주석·규칙 변경 |
| `build` | 빌드·패키징·배포 관련 |
| `chore` | 기타 잡무 (설정, 의존성 등) |

### 필수 템플릿
```
<type>(<scope>): <변경 내용을 한글로 한 줄 요약 — 50자 이내>

## 변경 이유 (Why)
배경과 근본 원인을 상세히 설명합니다.

## 변경 내용 (What)
- 파일명 — 구체적인 변경 내용 기술

## 영향 범위 (Impact)
이 변경이 다른 기능이나 파일에 미치는 영향 (없으면 "없음" 명시)
```

### 금지 및 주의 사항
- ❌ 제목 한 줄만 작성 (본문 생략 불가)
- ❌ 영어로만 작성 (본문은 반드시 한글)
- ❌ `--no-verify`로 훅 우회 금지
- ❌ 한글 주석 필수: 모든 코드 수정 시 한글 주석을 포함할 것.
