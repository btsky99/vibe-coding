# 🚀 계획 실행 프로토콜 (Execute Plan)

이 스킬은 `write-plan`으로 작성된 계획을 **정확하게** 실행합니다. 계획에 없는 작업을 임의로 추가하지 마십시오.

## 실행 원칙

1. **계획 파일 로드**: `ai_monitor_plan.md`를 읽어 전체 태스크 목록을 확인합니다.
2. **순서 준수**: 의존성이 있는 태스크는 반드시 선행 태스크 완료 후 시작합니다.
3. **단계별 보고**: 각 태스크 완료 시 "✓ Task N 완료: {무엇을 했는지}" 형식으로 보고합니다.
4. **즉각 중단 조건**: 예상치 못한 에러 발생 시 즉시 중단하고 `debug` 스킬을 호출합니다.

## 실행 사이클

```
태스크 시작 → 코드 수정 → 로컬 검증 → ✓ 체크 → 다음 태스크
                                ↓
                          실패 시 → debug 가동
```

## 완료 후 처리

1. **모든 태스크 완료 시**:
   - `CHANGELOG.md` 업데이트
   - `PROJECT_MAP.md` 관련 항목 최신화
   - `git add` → `git commit` (Conventional Commits 형식)
2. **하이브 로깅**: 작업 결과를 `.ai_monitor/data/task_logs.jsonl`에 기록합니다.
3. **최종 보고**: 완료된 태스크 목록과 변경된 파일 목록을 사용자에게 보고합니다.

## 🔗 다음 단계 안내
계획 실행 완료 후 사용자에게 제안:
- 코드 리뷰 스킬 — 변경된 코드 품질 검토
- 보안 점검 스킬 — 배포 전 OWASP 점검
- 릴리즈 스킬 — 빌드 및 배포
