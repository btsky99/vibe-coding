# 되돌리는 법 (2026-08-20 · 바탕화면 아이콘 + 제어판 등록 되돌리기)

## 무엇을 고쳤나
바탕화면 `바이브코딩.lnk` 와 제어판 "프로그램 제거" 항목이 **임시 폴더의 죽은 설치본**을
가리키고 있었다 — `%TEMP%\claude\D--vibe-coding\ffc9dbf6-.../scratchpad/v347`.
그 폴더는 윈도우 임시 청소가 이미 알맹이(`_appseed`)를 먹어 실행하면 즉시 터진다
(실측: `ImportError: can't find '__main__' module in ...\_appseed\.ai_monitor\server.py`).
둘 다 살아 있는 설치본 `%LOCALAPPDATA%\Programs\VibeCoding` (v3.7.341) 로 돌렸다.

## 되돌리기 1 — 바탕화면 아이콘
백업 파일이 그대로 있다. 덮어쓰기만 하면 원래대로다.

    copy /Y "%USERPROFILE%\Desktop\바이브코딩.lnk.bak-2026-08-20-deadtarget" "%USERPROFILE%\Desktop\바이브코딩.lnk"

## 되돌리기 2 — 제어판 등록
같은 폴더의 `uninstall_key_backup.reg` 를 더블클릭(또는 아래)하면 옛 값으로 돌아간다.

    reg import "D:\vibe-coding\backups\2026-08-20-shortcut-registry\uninstall_key_backup.reg"

## 🔴 옮기지 않은 것과 그 이유
- `%APPDATA%\VibeCoding\pgdata` (64.8GB) — **설치본(v3.7.341)이 옛 코드라 여전히 이 자리를 본다.**
  소스만 고치면 개발본과 설치본이 서로 다른 DB 를 보게 되고, 설치본은 빈 DB 를 새로 만든다
  (`server.py:291`). 판을 새로 구워 배포해야 같이 움직이는데 그건 사장 결재 사항이다.
- 설치본 · 관리 체크아웃 · `.claude\projects\` — 인스톨러/업데이터/클로드 코드가 정하는 자리.
- `D:\vibe-coding-auto` — git worktree. 본 폴더 안에 넣으면 본 리포의 `clean -fd` 에 지워진다
  (`heartbeat_daemon.py:231`).
