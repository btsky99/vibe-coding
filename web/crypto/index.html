CipherTrader (k-quant)

한국 주식 (KOSPI / KOSDAQ) AI 자동매매 시스템

한국투자증권(KIS) OpenAPI 실시간 데이터 수집부터 딥러닝 시계열 예측, 실시간 뉴스 감성 분석까지 일원화된 퀀트 트레이딩 데스크톱 애플리케이션입니다.

🚧 공개 배포 준비 중 · KIS OpenAPI 연동 완료

데이터 기반 퀀트 트레이딩

감정이 배제된 정밀한 AI 신호 분석으로 시장을 이깁니다.

🔌

KIS OpenAPI 실시간 연동

REST API 및 WebSocket을 활용하여 실시간 체결가, 호가, 분봉 데이터를 손실 없이 수집합니다.

🧮

시계열 AI 매매 신호

KOSPI/KOSDAQ 종목의 수급, 기술적 지표, 시계열 AI 모델(Transformer/LSTM)로 매수/매도 포지션을 산출합니다.

📰

뉴스·공시 감성 분석

실시간 공시 및 뉴스 텍스트를 LLM/NLP 파이프라인으로 분석하여 돌발 리스크와 매수 기회를 즉시 감지합니다.

🖥️

원스톱 셋업 패키지

데이터베이스, 모델 파이프라인, 트레이딩 대시보드가 원클릭으로 구동되는 Windows 설치형 앱입니다.

AI 매매 신호 생성 파이프라인

입력 데이터부터 주문 실행까지 4단계 자동화 체계

📡

1. 데이터 수집

KIS WebSocket 시세 + DART 공시 API

🧠

2. AI 분석

시계열 모델예측 + 뉴스 감성 점수 산출

⚖️

3. 리스크 검증

포트폴리오 비중 제약 및 손절선 검증
