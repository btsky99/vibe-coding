CipherTrader (k-quant)

파란이발의 한국 주식 (KOSPI/KOSDAQ) AI 자동매매 플랫폼

한국투자증권(KIS) OpenAPI 실시간 체결가 수집부터 시계열 AI 딥러닝 예측 모델, 실시간 뉴스 및 DART 공시 감성 분석을 종합해 정확한 매매 신호를 산출하는 퀀트 애플리케이션입니다.

⭐ GitHub (k-quant) 소스 보기 AI 시스템 안내 ↓
🚧 공개 배포 준비 중 · KIS OpenAPI 연동 완료

데이터 중심 AI 퀀트 트레이딩 (상세 안내)

감정을 배제하고 데이터와 AI 분석에 기반하여 주문을 실행합니다.

🔌

KIS OpenAPI 실시간 연동

한국투자증권 REST API 및 WebSocket으로 실시간 체결가, 호가, 분봉 데이터를 수집하고 정밀하게 처리합니다.

🧮

시계열 AI 딥러닝 예측

종목별 일봉, 수급 데이터, 시계열 AI 모델(Transformer/LSTM)을 통해 객관적인 매수/매도 타점을 계산합니다.

📰

뉴스 & DART 공시 감성 분석

실시간 공시 및 기업 관련 뉴스 텍스트 감성을 분석하여 리스크와 매수 호재 이벤트를 즉각 포착합니다.

🖥️

원스톱 데스크톱 셋업

DB, 모델 파이프라인, 트레이딩 대시보드가 한번에 셋업되는 Windows 설치형 애플리케이션입니다.
