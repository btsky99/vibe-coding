CipherTrader

한국 주식(KOSPI/KOSDAQ) AI 자동매매 시스템

KIS OpenAPI 실시간 시세에 시계열 AI와 뉴스·공시 감성 분석을 결합해 매매 신호를 생성하는 Windows 데스크톱 트레이딩 앱. 현재 개발 중입니다.

무엇을 하나요

데이터 · AI · 자동매매를 하나로.

🔌

KIS OpenAPI 연동

한국투자증권 REST/WebSocket으로 실시간 시세·분봉을 수집하고 주문을 실행.

🧮

시계열 AI 신호

KOSPI/KOSDAQ 일봉·수급 데이터를 학습해 매매 신호를 생성.

📰

뉴스·공시 감성

뉴스·공시 텍스트 감성 분석으로 이벤트 리스크와 기회를 포착.

🖥️

원스톱 설치

DB·모델·서비스까지 자동 셋업되는 Windows 데스크톱 앱(설치형).
