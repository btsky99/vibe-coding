Claude Code

Anthropic의 터미널 기반 코딩 에이전트. 프로젝트 분석, 구현, 테스트와 Git 작업을 지원합니다.

npm install -g @anthropic-ai/claude-code

OpenAI Codex CLI

로컬 저장소에서 코드를 이해하고 수정·검토·디버깅하는 OpenAI 터미널 코딩 에이전트입니다.

npm install --global @openai/codex
CLI 공식 문서 IDE 확장

Google Antigravity CLI

앱 설치 후 agy 사용

Google Gemini CLI
