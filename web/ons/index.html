OnS (On-Site Scheduling)

파란이발의 스마트 출장·장착 스케줄 관리 플랫폼

복잡한 출장 장착 스케줄을 자동으로 배정하고 동선을 최적화합니다. 오프라인 우선 설계로 통신이 불안정한 현장 환경에서도 데이터 손실 없이 완벽하게 작동합니다.

🌐 OnS 웹 앱 바로가기ons-swart.vercel.app 기능 안내 ↓
✅ 배포 서비스 구동 중 · Next.js + Firebase + PWA

현장에 최적화된 핵심 기능 (상세 안내)

작업자와 관리자 모두에게 필요한 기능만을 담았습니다.

📶

오프라인 우선 (Offline-First)

Firebase + IndexedDB 하이브리드 동기화 기술로 인터넷이 끊겨도 현장에서 일정 작성 및 조회가 유지됩니다.

🗺️

이동 동선 & 경로 최적화

방문 순서와 이동 시간 매트릭스를 자동으로 계산하여 기사님의 일별 이동 거리를 획기적으로 낮춰줍니다.

🗓️

자동 예약 스케줄링

고객 요청 시간, 작업 종류, 기사님 위치 정보를 조합하여 최적의 일정으로 자동 할당합니다.

💾

실시간 클라우드 백업

네트워크가 복구되면 로컬 데이터가 자동으로 클라우드에 백업되며 데이터 중복을 검증합니다.
