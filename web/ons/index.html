출장·장착 스케줄 관리 플랫폼

출장·장착 업무를 자동화하는 엔터프라이즈 스케줄 관리 시스템. 오프라인 우선 설계로 현장에 인터넷이 없어도 끊김 없이, 경로 최적화로 이동 시간까지 줄여줍니다.

핵심 기능

현장 업무에 최적화된 스케줄러.

📶

오프라인 우선

Firebase + IndexedDB 하이브리드로 인터넷이 끊겨도 예약·일정 관리가 그대로 동작.

🗺️

경로 최적화

방문 순서·이동 시간 매트릭스를 계산해 하루 동선을 효율적으로 배치.

🗓️

예약·일정 관리

출장·장착 예약을 등록·배정하고 진행 상태를 한눈에 추적.

💾

백업·복원

데이터 백업/복원과 중복 데이터 관리로 안전하게 운영.
