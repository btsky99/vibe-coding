OnS (On-Site Scheduling Platform)

스마트 출장·장착 스케줄 관리 플랫폼

복잡한 출장 장착 스케줄을 자동으로 배정하고 동선을 최적화합니다. 오프라인 우선 설계로 현장에 음영 지역이 있어도 데이터 손실 없이 완벽하게 작동합니다.

✅ 라이브 서비스 운영 중 · Next.js + Firebase + PWA

현장에 최적화된 핵심 기능

단순 스케줄러를 넘어 업무 효율을 최극대화합니다.

📶

오프라인 우선 (Offline-First)

Firebase + IndexedDB 하이브리드 동기화로 인터넷이 끊긴 지하 주차장이나 현장에서도 등록·일정이 상시 작동합니다.

🗺️

스마트 경로 최적화

방문 순서와 이동 시간 매트릭스를 자동으로 계산하여 기사님의 하루 이동 시간을 대폭 줄여줍니다.

🗓️

자동 예약 & 배정 Engine

고객 요청 시간, 작업 난이도, 담당자 위치를 종합 분석하여 최적의 일정으로 자동 할당합니다.

💾

자동 백업 & 중복 제거

실시간 클라우드 백업과 클라이언트 중복 관리로 현장 데이터를 안전하게 보존합니다.

OnS 현장 처리 프로세스

접수부터 완료 보고까지 원스톱으로 처리됩니다.

📝

1. 예약 접수

고객 접수 및 차량·장착 정보 입력

⚡

2. 스마트 배정

지역 및 동선 최적화 알고리즘 적용

🛠️

3. 현장 작업

오프라인 모드로 체크리스트 및 사진 저장
