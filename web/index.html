자주 묻는 질문

파란이발 서비스 가입, 관리자 로그인, 이용 안내입니다.

구글 또는 GitHub 소셜 로그인으로 가입할 수 있나요?
네, 우측 상단의 '소셜 로그인/가입' 버튼을 누르시면 Google 계정 또는 GitHub 계정 클릭 한 번으로 수동 아이디 입력 없이 1초 만에 가입 및 로그인이 진행됩니다.
관리자 계정(btsky99) 권한은 어떻게 받나요?
btsky99 구글/GitHub 소셜 계정으로 로그인하시면 시스템이 자동으로 인식하여 '👑 파란이발 관리자' 권한을 즉시 부여합니다.
바이브 코딩 및 OnS는 어디서 이용할 수 있나요?
바이브 코딩은 Windows 설치형 데스크톱 앱으로 다운로드하실 수 있으며, OnS는 웹 브라우저 및 모바일 앱으로 즉시 사용하실 수 있습니다.
